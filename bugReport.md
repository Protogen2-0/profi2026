1) ## страница авторизации :
    1.1 : войти можно под любым логином, сайт покажет "вы авторизовались", в ЛК отобразится "Пользователь не найден", страницы будут доступны, вызов функций происходит c ошибкой "пользователь не найден"

    1.2 : при пустом поле будет показано "вы авторизовались" при этом ничего не изменится на сайте

    1.3 : при вводе кириллицы в ЛК будет ошибка "Failed 
to execute 'fetch' on 'Window': Failed to read the 'headers' property from 'RequestInit': String contains non ISO-8859-1 code point."

    1.4 : ввод пробелов без других символов имеет такие же эффекты как и в 1.1

2) ## Функции :
    2.1 : функционал для ДПС виден водителям

    2.2 : в регистрации водителя ведется проверка на то есть ли ЗАЛОГИНЕННЫЙ пользователь в системе, а не тот логин который введен в полях ввода

    2.3 : IssueFine, при вводе несуществующей лицензии не выдается ошибка об ее отсутствии(выводится ошибка об незакрепленности лицензии к какому либо водителю)

    ? 2.4 : PayFine, при попытке нажать кнопку "оплатить" много раз когда штраф есть, будут выводиться ошибки транзакции "Transaction _ failed to commit with status code 11 (MVCC_READ_CONFLICT)", иногда транзакции будут с ошибкой "штраф уже оплачен" (штраф погасится после этого)

    2.5 : RegisterVehicle, срок эксплуатации и цена могут быть очень маленькими (0.000000001) или очень большими (3e300)

    ? 2.6 : PayFine, при вводе ID штрафа другого пользователя выдает ошибку что штрафа вообще нет

    2.7 : функционал для ДПС/водителей виден банку

3) ## Общее : 

    3.1 : AddLicence, добавление лицензий происходит по номеру + срок действия + категория, достаточно номера для проверки существования лицензии

    ? 3.2 : нет возможности убрать транспорт/лицензии, смена лицензии

    3.3 : ДПС после отправки штрафа другому пользователю в истории в ЛК ДПС-а не отобразится сообщение о выписке штрафа, хотя у другого пользователя информация об получении штрафа появится 

    3.4 : нет возможно создать ДПС так чтобы он не был водителем

    3.5 : ЛК, так как пользователь может иметь одну лицензию, нет смысла у каждого ТС указывазывать категорию, она всегда соответствуют категории лицензии

    3.6 : для "регистрации" требуется авторизоваться
